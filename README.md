# Tab Number Hints

只为 Chrome 原生的数字切换快捷键显示提示。不配置、不执行、不拦截快捷键；不依赖 Shortkeys。

## 安装

1. 停用原有 Shortkeys（包括之前修改过的开发版），避免两个扩展同时修改标题。无需卸载。
2. 打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件夹 `tab-number-hints`，不要选它的上级目录。
4. 刷新已经打开的普通网页，使页面加载扩展脚本。

加载即用，没有开关或设置页。无需 npm、编译或构建输出目录。不要移动或删除已加载的文件夹；更新文件后在扩展管理页点击「重新加载」，再刷新网页。

## 使用

在网页内按住 **Command（macOS）**，或 **Ctrl（Windows/Linux）**：

- 前八个标签显示 `[1]`～`[8]`。
- 最后一个标签显示 `[9]`。
- 最后一个也位于前八个时合并显示，例如第五个兼末尾显示 `[5/9]`。
- 超过八个且不是末尾的标签不显示数字，因为 Chrome 没有直接对应的数字快捷键。

按数字的切换操作仍由 Chrome 完成。松开前缀键恢复标题；额外按住 Shift、Alt 或另一种前缀键时不显示。输入框和可注入的 iframe 中也可以触发。

切换标签后松键、拖动标签、标签数量变化、窗口失焦都会调整或清理提示。网页自己更新标题时保留最新标题，不会误删原本以数字开头的内容。

## 范围限制

- 焦点在地址栏、浏览器菜单等浏览器界面中时，扩展收不到按键。
- `chrome://` 页面、Chrome 应用商店和其他扩展页面不能注入脚本；其他扩展提供的新标签页也不支持。
- 切换到不能监听松键的页面会清除其他标签的提示，避免数字残留。
- 固定标签不显示标题，因此看不到前缀，但仍参与编号。
- 被丢弃或冻结的标签不能保证立即更新标题；重新加载后才能正常处理。
- 本地文件页面需要在扩展详情中开启「允许访问文件网址」。

## 实现与权限

- `manifest.json`：Chrome Manifest V3 清单。
- `content.js`：监听页面中的前缀键；顶层页面临时修改标题并恢复。
- `background.js`：按当前窗口的真实标签顺序分配数字，处理标签和窗口生命周期。

唯一显式权限为 `storage`：仅使用内存中的 `chrome.storage.session` 保存当前窗口的临时按住状态，让后台服务工作线程休眠后仍能正确处理松键。不使用本地或同步存储，不保存标题、网址或浏览历史，不联网、不统计使用情况。

页面脚本声明覆盖 HTTP、HTTPS 和本地文件，用于观察按键及修改标题；不申请 `tabs`、`scripting`、`debugger`、剪贴板或历史记录权限。

## 验证

已在独立临时配置目录的无界面 Chrome for Testing 中验证 macOS 按键路径：十二个标签的编号、跨标签松键、动态标题与原生数字前缀恢复、额外修饰键、合并末尾编号、连续重复按住、拖动排序、iframe 输入、受限页面清理、跨窗口移动，以及真实停止并重启后台工作线程后的松键恢复。未操作日常 Chrome。Windows/Linux 分支尚未在对应操作系统实测。
