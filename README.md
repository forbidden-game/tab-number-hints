# Tab Number Hints

按住 **Command（macOS）** 或 **Ctrl（Windows/Linux）**，Chrome 标签栏直接显示原生数字切换提示。不配置、不执行、不拦截快捷键，也不依赖 Shortkeys。

## 使用

- 前八个标签显示 `[1]`～`[8]`，最后一个标签显示 `[9]`；两者重合时合并显示，例如第五个兼末尾是 `[5/9]`。
- 超过八个且不是末尾的标签不显示数字，因为 Chrome 没有直接对应的快捷键。
- 修饰键按住期间，切换标签、拖动标签、按 Shift/Alt 都不会让数字消失；松开后恢复原标题。
- 网页自己更新标题时保留最新标题，不会误删原本以数字开头的内容。

## 安装

1. 打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本文件夹，不要选它的上级目录。
3. 刷新已经打开的普通网页。

没有开关和设置页，无需 npm、编译或构建输出目录。改动文件后在扩展管理页点击「重新加载」，再刷新网页。本扩展与 Shortkeys 等同样改写标题的工具功能重叠，建议只保留一个。

## 范围限制

- 地址栏、浏览器菜单等浏览器界面，以及 `chrome://` 页面、应用商店和其他扩展页面收不到按键，也无法给自身标题加数字；切换到这些页面时，其他标签的数字会保留。
- 若在受限页面或浏览器界面中松开修饰键，扩展无法立即获知：回到普通网页后，下一次按键或鼠标输入会校正状态，浏览器窗口失焦也会清理。
- 固定标签不显示标题，因此看不到前缀，但仍参与编号。
- 被丢弃或冻结的标签不能保证立即更新标题，重新加载后才能正常处理。
- 本地文件页面需要在扩展详情中开启「允许访问文件网址」。

## 实现与权限

- `manifest.json`：Chrome Manifest V3 清单。
- `content.js`：观察修饰键状态，临时改写顶层标题并在松键后恢复；用鼠标输入校正浏览器界面中错过的状态变化。
- `background.js`：按当前窗口的真实标签顺序分配数字，处理标签与窗口生命周期；标签切换不算松键。
- `icons/`：扩展图标，含 16、32、48、128 像素 PNG 与 1024 像素母版。

唯一显式权限是 `storage`，且只使用内存中的 `chrome.storage.session` 保存当前窗口的临时按住状态。不联网、不统计使用情况，不保存标题、网址或浏览历史。

## 验证

已在隔离配置的 Chrome for Testing 中加载真实扩展，跑通编号映射、按住期间连续切换、跨标签松键、受限页面、iframe、动态标题等流程；另用系统输入流验证了原生 Command+2/3 连续切换后的标签栏显示。Windows/Linux 分支尚未实测。
